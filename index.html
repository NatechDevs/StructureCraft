A FEW USEFUL DETAILS

Before you start.

Read the full guide
Do my files leave my device?+

No. Folder paths and pasted trees are processed in your browser. StructureCraft does not read file contents or send your project to a server.

Can I start from an existing tree?+

Yes. Paste a Unicode or ASCII tree with one root and consistent indentation. You can edit it in the workspace before exporting.

Does the ZIP include my original files?+

No. ZIP exports contain the visible directories and empty placeholder files. Use them to scaffold a layout, rather than back up file contents.

Do I need to create an account?+

No account or installation is required. Your project remains in page memory. Only your light or dark theme preference is saved in your browser.
