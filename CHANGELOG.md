# Changelog

Notable project changes are recorded here. Entries under Unreleased are available on `main` and do not imply a published version tag or hosted deployment.

## Unreleased

### Added

- Product landing page with an interactive output example.
- Dedicated workspace and public documentation pages.
- Unicode/ASCII trees, Markdown and JSON output, and ZIP scaffolds.
- Filter presets, path search, depth controls, hidden-entry controls, and source-tree editing.
- Light and dark themes with a saved appearance preference.
- Keyboard-accessible mobile navigation and a shared footer with developer credit.
- Self-hosted Poppins fonts with their SIL Open Font License notice.
- Static production packaging and Vercel configuration.
- MIT project license, third-party notices, contribution and conduct guidelines, security reporting policy, and GitHub issue/pull request templates.

### Changed

- Replaced the original PHP-heavy page with a static application; retained a local XAMPP entry point.
- Removed browser shortcut restrictions, source obfuscation, external UI libraries, and external font requests.
- Kept development and deployment instructions in repository documentation rather than the public user guide.
