PRODUCT GUIDE

A clear view of your project.

Create directory trees for project documentation, technical handoffs, and new project scaffolds. Learn how to choose a source, refine the structure, and export the result.

01. Quick start

  1. Open the workspace and select Browse folder. You can also use the example project or paste a tree.
  2. Choose a preset, adjust the root name, and remove irrelevant entries with exclusions or the path filter.
  3. Choose Tree, Markdown, or JSON. Copy the result or download it.
  4. Use Export ZIP when you need a new folder scaffold with empty placeholder files.

All export actions follow the currently visible structure. A path filter, depth limit, or exclusion can remove entries from your export.

02. Import a local folder

Select a single project directory through your browser’s folder picker. StructureCraft uses relative file paths to reconstruct the hierarchy. It never reads file contents.

Your browser may describe folder selection as an “upload.” The selected paths are processed on your device; the project files are not sent to StructureCraft.

Folder import supports up to 50,000 files and 100 nested directories below the root. Empty directories may be absent because browsers generally expose files rather than standalone folder entries. Use a pasted tree to include empty directories.

03. Paste and edit trees

Select Paste tree, enter your structure, then select Apply tree. Changes remain a draft until you apply them. The existing preview is preserved if parsing fails.

project/
├── config.d/
│   └── settings.json
├── src/
│   └── index.js
├── empty-directory/
└── LICENSE

Use a single root. Each nested level occupies four characters: │ , | , or four spaces. Supported branch markers are ├── , └── , |-- , `-- , and +-- . Plain four-space indentation also works.

A trailing / or the presence of children marks a directory. Other entries are files. This supports both dotted folders such as config.d/ and extensionless files such as LICENSE. Unicode names and fenced Markdown code blocks are accepted.

Each entry needs a distinct name within its parent folder. Avoid path separators inside names, control characters, dot-only names, skipped indentation levels, and multiple roots. The limit is 20,000 lines and 100 nested levels.

Edit the source

The pencil button loads the complete source tree into the paste editor. Excluded entries remain in that source. Temporary preview filters do not remove entries from the editable source. If you renamed the root in Output settings, the editor still shows its original name.

04. Filters and presets

ControlBehavior
DocumentationExcludes node_modules, .git, dist, build, .next, coverage. Includes hidden entries and all nesting levels.
Complete projectClears exclusions, includes hidden entries, includes files, and removes the depth limit.
Directories onlyUses the Documentation exclusions and omits files.
CustomSelected automatically when you change exclusions, visibility, or depth.
Maximum depthThe root is level 0. A depth of 1 includes its direct children. Descendants beyond the selected depth are omitted.
Excluded namesCase-insensitive, whole-name matching at every level. Commas separate patterns. * matches any sequence of characters. Excluding a directory removes its whole subtree.
Path filterCase-insensitive substring matching against full relative paths, including the root name. Matching files keep their ancestor directories. A matching directory includes eligible descendants.

Examples: *.log excludes log files; test* excludes names beginning with “test”; src/components in the path filter focuses the preview on that part of the project. Exclusions take effect before path filtering. A depth limit still applies during a search.

Path search does not search file contents. When no entries match, the preview retains the root folder and reports “No matching entries — root only.” Folder counts include that root. Sorting always places directories first, then names in numeric-aware alphabetical order.

05. Export formats

FormatResultUse it for
Tree / .txtPlain UTF-8 text in Unicode or ASCII branch style.Notes, documents, code reviews.
Markdown / .mdThe tree inside a fenced text code block. Fences adapt to backticks in names.README files and Markdown documentation.
JSON / .jsonA nested object with explicit file and directory types.Other tools and custom processing.
ZIP / .zipVisible directory structure with empty files and explicit directory entries.Scaffolding a project or sharing a proposed layout.

Copy output and Download use the selected format. Export ZIP always exports the structure independently of the selected tab. ZIP exports preserve Unicode names and support up to 65,535 files and directories combined.

A ZIP is a scaffold, not a backup. It never includes the contents of your selected files. Names valid on one operating system may require changes before extraction on another.

06. Working with JSON

Each node has a name and type. Directory nodes include a children array, including an empty array for empty directories. File nodes have no children property.

{
  "name": "project",
  "type": "directory",
  "children": [
    {
      "name": "src",
      "type": "directory",
      "children": [
        { "name": "index.js", "type": "file" }
      ]
    }
  ]
}

JSON is useful when another tool needs to read the hierarchy. Exports follow the same filters, root name, and depth as the preview. Branch style affects Tree and Markdown only. StructureCraft exports JSON; to bring a structure into the workspace, use a folder or a text tree.

07. Keyboard controls

  • Tab / Shift+Tab: move between controls. A skip link takes you directly to the workspace.
  • Left / Right arrows: switch tabs within the active tab group.
  • Home / End: select the first or last tab in the group.
  • Space: toggle switches or activate a focused button.
  • Escape: leave focused preview mode.
  • Ctrl+C / ⌘C: copy a manual text selection. Normal browser shortcuts are available.

The expand button hides source settings while keeping the preview, filter, and exports visible. Activate it again or press Escape to restore the complete workspace.

08. Privacy and limitations

Folder paths and pasted content exist in page memory. StructureCraft does not transmit or save project paths and pasted content, create accounts, or run analytics. Refreshing or closing the page clears the workspace. Only your light or dark appearance preference is saved in this browser. Fonts and interface assets are served with the application.

The hosting provider serves the page and may maintain ordinary request logs according to its policies. Downloaded exports and clipboard content are handled by your browser and operating system. Exclusions are a presentation filter, not a guarantee that an export contains no sensitive names: review the preview before sharing.

Folder selection requires a browser that supports directory picking. If your browser does not offer folder selection, use Paste tree instead. Very large structures can take time to render, especially on mobile devices. Deeply nested filesystems and filenames are also subject to operating-system limits.

09. Common questions

The clipboard button cannot copy

Your browser may restrict clipboard access. If copying is unavailable, StructureCraft selects the output so you can copy it manually with Ctrl+C or ⌘C.

Some entries are missing

Check the path filter, exclusions, hidden-entry switch, directories-only switch, and depth limit. Choose Complete project and clear the path filter to inspect all imported paths. Empty directories may be absent from browser folder selection.

A pasted tree fails to parse

Check for a single root, consistent four-character indentation, duplicate names, and unsupported comments. Remove tree-command summaries such as “3 directories, 5 files.” Comments alongside names become part of the name, so remove annotations before importing.

Why does the tree show only the root folder?

No entries match the current filters. Clear the path filter and choose Complete project to review all imported entries. The root remains visible even when every child is filtered out.

I need the original files in a ZIP

StructureCraft intentionally creates a layout only. Use your operating system’s archive tool to package original file contents.
